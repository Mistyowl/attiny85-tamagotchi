# Жорик — путь пользователя и функционал

Документ для доски Miro / ТЗ. Описывает, что происходит на **физическом** тамагочи (ATtiny85 + OLED 128×64 + 3 кнопки). Отличия эмулятора помечены отдельно.

---

## 0. Железо и ввод

| Элемент | Роль |
|---------|------|
| **Left ◀** | Назад по меню / влево (ракетка в играх) |
| **Select ●** | Подтвердить действие / прыжок / разбудить / после смерти Select ×3 = рестарт |
| **Right ▶** | Вперёд по меню / вправо (ракетка в играх) |
| **Экран** | SSD1306 OLED **128×64**, монохром 1-bit |
| **Звук** | Пищалка на общем пине с Left |
| **Питание** | OLED гаснет в idle; **первое нажатие только будит**, действие не срабатывает |

Подписи меню на экране (одна выбранная): **ЕДА · ИГРА · СОН · ЛЕК**.

---

## 1. Полный путь жизни (user journey)

```
Включение → Boot (короткий сплэш)
    ↓
Яйцо (Egg) — меню видно, уход почти не работает
    ↓  ~30 life-тиков (~4 мин реального времени при WDT ~8 с)
Маленький (Baby)
    ↓  age ≥ 180
Средний (Child)
    ↓  age ≥ 360
Взрослый (Adult / AdultA / AdultB — от careScore)
    ↓
Цикл ухода: ЕДА / ИГРА / СОН / (ЛЕК при болезни или грязи)
    ↓
Если не ухаживать → health → 0
Смерть (крылья + полёт вверх) → «УВЫ» / «ЖМИ»
    ↓  Select ×3
Новый цикл (Boot → яйцо)
```

Параллельно всегда идут decay статов и редкие события; состояние пишется в EEPROM.

---

## 2. Главный экран (Home)

### Что видит пользователь

- Спрайт текущей стадии (моргание)
- Полоски статусов: голод (насыщенность), счастье, энергия, здоровье
- Внизу — **одна** подпись выбранного пункта меню (инвертом)
- При болезни — текст **БОЛ**
- При грязи — какашка; коротко может быть **НАДУДОНИЛ**
- При низкой энергии — иконки Zzz

### Управление

| Кнопка | Действие |
|--------|----------|
| ◀ / ▶ | Листать меню по кругу |
| Select | Выполнить выбранное действие |

В стадии **Egg** Select даёт только клик/фидбек — кормить/играть/спать ещё нельзя по смыслу геймплея.

## 3. Активности

### 3.1 ЕДА

| | |
|--|--|
| **Когда** | Home, не яйцо |
| **Как** | Меню → ЕДА → Select |
| **Эффект** | hunger −25, careScore +1 |
| **Побочка** | ~1/4 шанс событие «Надудонил» (флаг грязи) |
| **Звук** | Feed |

---

### 3.2 ИГРА

| | |
|--|--|
| **Когда** | Home, не яйцо |
| **Как** | Меню → ИГРА → Select |
| **Что запускается** | Одна из трёх мини-игр |
| **Выбор игры на железе** | **Нет — случайный выбор** (см. ниже) |
| **После выхода** | +счастье от результата, −энергия, care↑, возврат в Home |

#### Как выбрать конкретную игру на физическом тамагочи?

**Сейчас — никак.** На устройстве Play всегда берёт случайную игру из трёх.

Выбор конкретной игры есть **только в веб-эмуляторе** (lab: RAND / ПОНГ / БЛОК / ПРЫГ).

> **Продуктовый gap:** если нужен выбор на железе — нужна доработка (например: ИГРА → подменю ПОНГ / БЛОК / ПРЫГ → Select).

#### Мини-игры

##### ПОНГ

| | |
|--|--|
| **Управление** | ◀ / ▶ удерживать — двигать ракетку |
| **Геймплей** | Мяч, своя ракетка снизу, AI сверху |
| **Конец** | 20 попаданий **или** 3 промаха |
| **Награда** | Счастье от попаданий; энергия−; care↑ |

##### БЛОК (Arkanoid)

| | |
|--|--|
| **Управление** | ◀ / ▶ — ракетка |
| **Геймплей** | Кирпичи (часть на 1 удар, часть на 2), случайный layout |
| **Конец** | Все кирпичи сбиты **или** 3 промаха |
| **Награда** | Счастье / энергия / care по результату |

##### ПРЫГ (Runner)

| | |
|--|--|
| **Управление** | **Любая** кнопка = прыжок |
| **Геймплей** | Бег, прыжки через препятствия |
| **Конец** | 12 успешных **или** 3 промаха |
| **Награда** | Счастье / энергия / care по результату |

---

### 3.3 СОН

| | |
|--|--|
| **Когда** | Home, не яйцо |
| **Как** | Меню → СОН → Select |
| **Экран** | Закрытые глаза, Zzz, текст **СОН**, полоска энергии |
| **Эффект** | По life-тикам энергия↑ (+12), голод чуть↑ |
| **Выход** | Select = разбудить **или** авто, когда энергия ≥ 85 |

---

### 3.4 ЛЕК (лечение)

| | |
|--|--|
| **Когда появляется в меню** | Только если болен (**SICK**) и/или грязный (**DIRTY**) |
| **Как** | Меню → ЛЕК → Select |
| **Эффект** | Снимает болезнь и грязь, health +15, care +1 |
| **Звук** | Medicine |

## 4. Пассивные состояния и угрозы

| Событие | Условие | Что видит / что происходит |
|---------|---------|----------------------------|
| **Болезнь** | Высокий голод (и тики) | «БОЛ», здоровье↓ |
| **Грязь** | Редкий life-тик (~каждые 32 тика, шанс) или после еды | Какашка, «НАДУДОНИЛ» |
| **Сонливость** | Энергия низкая | Zzz у спрайта |
| **Decay** | Каждый life-тик (не сон / не игра) | hunger↑, happiness↓, energy↓; при плохих статах health↓ |
| **Смерть** | health = 0 | Крылья по бокам, полёт вверх → «УВЫ» / «ЖМИ» |
| **Рестарт** | На экране смерти нажать Select **×3** | Новый пет с Boot |

На смерти спрайт тела соответствует **текущей стадии** (маленький soul-арт только для Baby).

## 5. Эволюция

| Стадия | Условие перехода | Внешний вид |
|--------|------------------|-------------|
| **Egg** | Старт | Яйцо |
| **Baby** | ageTicks ≥ 30 | Маленький хомяк |
| **Child** | ageTicks ≥ 180 | Средний |
| **Adult** | ageTicks ≥ 360, care 31…79 | Большой (обычный) |
| **AdultA** | ageTicks ≥ 360, care ≥ 80 | Ветка «хороший уход» |
| **AdultB** | ageTicks ≥ 360, care ≤ 30 | Ветка «плохой уход» |

`careScore` растёт от еды, игр, лечения.

---

## 6. Сохранение

- EEPROM blob ~17 байт: стадия, статы, флаги, возраст, care, CRC  
- При старте: если health = 0 → сразу экран смерти; если sleeping → сон  
- В эмуляторе — localStorage с тем же форматом

## 7. Только эмулятор (не на железе)

| Фича | Зачем |
|------|--------|
| Force minigame (RAND / ПОНГ / БЛОК / ПРЫГ) | Выбрать игру вручную |
| Time scale | Ускорить жизнь |
| Skip маленький / средний / большой | Быстрый тест стадий |
| OLED stay on / buzzer mute | Отладка |
| Облачный корпус UI | Визуал сайта, не прошивка |

## 9. Как разложить на доске Miro

1. **Горизонтальная лента:** Boot → Egg → Baby → Child → Adult → Death → Restart  
2. Под каждым этапом — стикеры: *Видит / Жмёт / Эффект / Звук*  
3. Отдельная колонка **Активности:** ЕДА · ИГРА · СОН · ЛЕК  
4. Под ИГРА — три карточки мини-игр  
5. Колонка **Gaps** (красным): нет выбора игры на железе, …  
6. Колонка **Только эмулятор** (серым)
