# Жорик — функционал, заливка и пайка

Документ для сборки физического устройства: **ATtiny85-20PU + SSD1306 128×64 I2C + 3 кнопки + пьезо HPA17A + CR2032** на макетке **80×20 мм**. OLED ставится на стойки в корпусе и подключается проводами к той же плате.

Пины и ограничения железа: [`constraints.md`](constraints.md). Путь игрока: [`user-journey.md`](user-journey.md).

---

## 1. Весь функционал на данный момент

Источник правды по геймплею: `shared/pet.ts`, `shared/minigame.ts`, `shared/phase2.ts`. Прошивка — C-порт тех же механик; UI на чипе беднее эмулятора (см. §1.10).

### 1.1 Жизненный цикл

```
Включение → Boot (короткий сплэш)
  → Egg (меню видно, уход почти не работает)
  → Baby   (age ≥ 450 life-тиков  ≈ 1 ч при WDT ~8 с)
  → Child  (age ≥ 43 200 ≈ 4 сут)
  → Adult / AdultA / AdultB  (age ≥ 302 400 ≈ 28 сут, ветка от careScore)
  → цикл ухода / decay / события (без смерти от старости)
  → health = 0 → Dead (крылья + полёт вверх)
  → Select ×3 → новый пет (Boot → Egg)
```

| Стадия | Условие | careScore при эволюции |
|--------|---------|------------------------|
| Egg | старт | — |
| Baby | `ageTicks ≥ 450` (~1 ч) | — |
| Child | `≥ 43 200` (~4 сут) | — |
| Adult | `≥ 302 400` (~28 сут) | 31…79 |
| AdultA | `≥ 302 400` | ≥ 80 (хороший уход) |
| AdultB | `≥ 302 400` | ≤ 30 (плохой уход) |

Стартовые статы нового пета: hunger **20**, happiness **80**, energy **90**, health **100**, careScore **50**.

### 1.2 Статы (0–100)

| Стат | Смысл | Decay (не сон / не мини-игра) |
|------|--------|--------------------------------|
| **hunger** | плохо когда высокий | +1 каждые 32 тика; на UI «насыщенность» = `100 − hunger` |
| **happiness** | плохо когда низкий | −1 каждые 32 тика |
| **energy** | усталость | −1 каждые 32 тика awake; во сне +1 каждые 64 |
| **health** | смерть при 0 | −1 каждые 16 тиков при стрессе (hunger≥85 / happy≤15 / energy≤15); −1 каждые 32 если SICK |

**careScore** растёт от еды (+1), игр, лечения (+1). Влияет на AdultA/B.

Life-тик ≈ **8 с** реального времени (WDT). Без сна с полных статов смерть ~за **8 ч**; уложенный спать переживает ночь (~8 ч).

### 1.3 Кнопки

Не A/B/C — **Left / Select / Right** (◀ / ● / ▶):

| Кнопка | Пин | Home | Sleep | Dead | ПОНГ / БЛОК | ПРЫГ |
|--------|-----|------|-------|------|-------------|------|
| **Left** | PB1 | меню назад | — | — | ракетка влево (hold) | прыжок |
| **Select** | PB3 | подтвердить | разбудить | ×3 рестарт | БЛОК: пауза | прыжок |
| **Right** | PB4 | меню вперёд | — | — | ракетка вправо | прыжок |

Эмулятор: ← Left, → Right, Enter / Space = Select.

### 1.4 Экраны (FSM)

| Screen | Поведение |
|--------|-----------|
| **Boot** | сплэш; любая кнопка → Home сразу, иначе через несколько тиков |
| **Home** | спрайт + статы + меню действий |
| **Sleeping** | энергия↑; Select будит; авто при energy ≥ 85 |
| **Dead** | анимация полёта → «УВЫ» / «ЖМИ» (эмулятор); Select ×3 = рестарт |
| **Minigame** | ПОНГ / БЛОК / ПРЫГ; life-decay на паузе |

### 1.5 Меню Home

◀/▶ листают по кругу, Select подтверждает.

| Действие | Когда | Эффект | Звук |
|----------|-------|--------|------|
| **ЕДА** | не Egg (на Egg — только клик) | hunger −25, care +1; ~1/4 шанс DIRTY | Feed |
| **ИГРА** | не Egg | мини-игра (на железе — **случайная** из трёх) | Play |
| **СОН** | не Egg | → Sleeping | Sleep |
| **ЛЕК** | только SICK и/или DIRTY | снимает оба флага, health +15, care +1 | Medicine |

### 1.6 Мини-игры

На железе Play = **случайный** выбор. Выбор конкретной игры — только в веб-эмуляторе (lab: RAND / ПОНГ / БЛОК / ПРЫГ).

| Игра | Управление | Конец | Награда |
|------|------------|-------|---------|
| **ПОНГ** | ◀/▶ hold — ракетка | 20 попаданий **или** 3 промаха | happy от hits; energy−; care↑ |
| **БЛОК** | ◀/▶; Select = пауза | все кирпичи **или** 3 промаха | то же |
| **ПРЫГ** | **любая** кнопка = прыжок | 12 успехов **или** 3 промаха | то же |

### 1.7 Сон

- При входе energy capped до **30** (длинный авто-сон даже если был бодр).
- +1 energy каждые 64 тика (~8.5 мин), +1 hunger каждые 128 (~17 мин); happiness/health во сне не падают.
- Выход: Select или energy ≥ 85 → с cap 30 автопробуждение ≈ **7.8 ч**.
- Правило: **уложи спать на ночь** — иначе awake-decay может убить за ночь.

### 1.8 Пассивные угрозы

| Событие | Условие | Эффект |
|---------|---------|--------|
| **SICK** | высокий hunger + тики | «БОЛ»; health −1/тик |
| **DIRTY** | низкий happy / после еды / редкий тик | какашка; «НАДУДОНИЛ» |
| **Decay** | каждый life-тик вне сна/игры | hunger↑, happy↓, energy↓ |
| **Смерть** | health → 0 | Die SFX, крылья, полёт |
| **Рестарт** | Select ×3 на Dead | новый пет |

### 1.9 Сохранение (EEPROM 17 байт)

| Offset | Field |
|--------|-------|
| 0 | magic `0x54` ('T') |
| 1 | version `1` |
| 2 | stage |
| 3–6 | hunger, happiness, energy, health |
| 7 | flags: bit0 sick, bit1 dirty, bit2 sleeping |
| 8–11 | ageTicks u32 LE |
| 12–15 | careScore u32 LE |
| 16 | CRC8(bytes 0–15) |

Автосейв примерно каждые 50 life-тиков. Эмулятор: `localStorage` с тем же форматом.

### 1.10 Звук (SFX)

Пищалка **HPA17A** (пассивный пьезо, без встроенного генератора) на общем пине с Left.

| ID | Имя | Когда |
|----|-----|-------|
| 1 | Click | меню ◀/▶ |
| 2 | Feed | еда |
| 3 | Play | старт/конец игры |
| 4 | Sleep | уход в сон |
| 5 | Medicine | лечение |
| 6 | Hatch | Egg→Baby |
| 7 | Evolve | эволюция |
| 8 | Chirp | idle, happy≥50 |
| 9 | Sad | плохие статы |
| 10 | Die | смерть |
| 11 | Wake | разбудить |
| 12 | Hit | мини-игра — **только эмулятор** |
| 13 | Fart | dirty-события — **только эмулятор** |

### 1.11 Что на устройстве vs только эмулятор

| Есть на ATtiny85 | Только эмулятор / gap прошивки |
|------------------|--------------------------------|
| Жизненный цикл, статы, меню, 3 мини-игры | Выбор конкретной мини-игры вручную |
| Сон, болезнь, грязь (базовая логика), смерть, EEPROM | Полный UI: кириллица, иконки, poop-bitmap, «НАДУДОНИЛ» |
| SFX 1–11 на пьезо | Hit / Fart SFX; time scale; skip stage; battery lab |
| SoftI2C OLED 128×64 | OLED auto-off / PCINT wake — задуманы, на железе не доведены |

## 2. Схема заливки кода через Arduino Uno (ISP)

**Без Micronucleus / Digispark USB-bootloader** — он съедает ~1.5–2 KB Flash, текущая прошивка не влезет. Только **ISP**.

Рекомендуемый порядок: прошить чип **в DIP-сокете на breadboard** (или вынув из готовой платы), **без OLED и без CR2032**. Пины PB0/PB2 во время ISP — это MOSI/SCK; если OLED подключён, заливка часто срывается. Uno даёт **5 V**, батарея — **3 V**: не подключай оба сразу.

### 2.1 Что нужно

- Arduino Uno
- ATtiny85-20PU + breadboard / DIP-сокет
- 6 проводов
- Конденсатор **10 µF** (электролит: «−» на GND)
- ПК с AVR-GCC + avrdude (`winget install ZakKemble.avr-gcc`)
- Arduino IDE (один раз — залить скетч ArduinoISP на Uno)

### 2.2 Шаг 1 — сделать из Uno программатор

1. Подключи Uno к ПК по USB.
2. Arduino IDE → **File → Examples → 11.ArduinoISP → ArduinoISP**.
3. Board: **Arduino Uno**, свой COM-порт → **Upload**.
4. После заливки Uno сам по себе уже не «скетч пользователя», а ISP-программатор.

### 2.3 Шаг 2 — конденсатор на RESET Uno

Между выводом **RESET** Uno и **GND** поставь **10 µF** (минус конденсатора на GND).

Зачем: при открытии serial-порта Windows/avrdude дёргает DTR → Uno сбрасывается и ISP обрывается. Конденсатор это глушит. **Сними конденсатор**, когда снова захочешь заливать обычный скетч на сам Uno.

### 2.4 Шаг 3 — распиновка ATtiny85 (вид сверху, выемка сверху)

```
        ┌────U────┐
  RESET │1      8│ VCC
    PB3 │2      7│ PB2 (SCK / SCL)
    PB4 │3      6│ PB1 (MISO / Left / Buzz)
    GND │4      5│ PB0 (MOSI / SDA)
        └─────────┘
```

### 2.5 Шаг 4 — провода Uno → ATtiny85

| Arduino Uno | ATtiny85 | Сигнал |
|-------------|----------|--------|
| **D10** | Pin 1 | RESET |
| **D11** | Pin 5 (PB0) | MOSI |
| **D12** | Pin 6 (PB1) | MISO |
| **D13** | Pin 7 (PB2) | SCK |
| **5V** | Pin 8 | VCC |
| **GND** | Pin 4 | GND |

```
 Arduino Uno                          ATtiny85
 ┌──────────┐                        ┌────U────┐
 │ D10  ──────── RESET ─────────────│1      8│─── 5V
 │ D11  ──────── MOSI  ─────────────│5      7│─── D13 (SCK)
 │ D12  ──────── MISO  ─────────────│6      6│
 │ D13  ──────── SCK   ─────────────│7      5│─── D11 (MOSI)
 │ 5V   ──────── VCC   ─────────────│8      4│─── GND
 │ GND  ──────── GND   ─────────────│4      2│  (не ISP)
 │          │   10µF: RESET──┤├──GND │      3│  (не ISP)
 └──────────┘                        └─────────┘
```

Проверь мультиметром: VCC–GND не закорочены; чип ориентирован правильно (точка/выемка у Pin1).

### 2.6 Шаг 5 — fuse-ы на 8 МГц (один раз на чип)

Прошивка собрана с `F_CPU = 8000000`. С завода часто стоит делитель CKDIV8 → реально **1 МГц**, игра будет тормозить. Выставь внутренний RC **8 МГц**:

```bash
avrdude -c arduino -P COM3 -b 19200 -p t85 -U lfuse:w:0xE2:m -U hfuse:w:0xDF:m -U efuse:w:0xFF:m
```

Подставь свой COM-порт (`режим устройств` / Arduino IDE → Tools → Port).

| Fuse | Значение | Смысл |
|------|----------|--------|
| lfuse `0xE2` | внутренний 8 МГц, CKDIV8 выкл. |
| hfuse `0xDF` | SPIEN вкл. (можно прошивать снова), BOD выкл. |
| efuse `0xFF` | по умолчанию |

**Не ставь** fuse, отключающий RESET (RSTDISBL) — потом только HV-программатор.

### 2.7 Шаг 6 — собрать hex и залить flash

```bash
cd firmware
make hex
avrdude -c arduino -P COM3 -b 19200 -p t85 -U flash:w:build/zhorik.hex:i
```

Успех: avrdude пишет `avrdude done. Thank you.` Чип можно вынуть и вставить в сокет на плате устройства.

### 2.8 Типичные ошибки

| Симптом | Что проверить |
|---------|----------------|
| `not in sync` / timeout | конденсатор 10 µF на RESET Uno; верный COM; ArduinoISP залит |
| `Yikes! Invalid device signature` | перепутаны MOSI/MISO/SCK; плохой контакт; питание |
| Экран после сборки молчит | fuse не 8 МГц; OLED на других пинах; нет общего GND |
| Заливка ок на breadboard, в плате — нет | отключи OLED на время ISP; не питай от CR2032 и Uno вместе |

## 3. Полная электрическая схема устройства

### 3.1 Карта пинов (игра + пьезо)

| ATtiny pin | Port | Куда |
|------------|------|------|
| 1 | PB5 / RESET | не к сигналам игры; можно вывести площадку ISP |
| 2 | PB3 | кнопка **Select** → GND |
| 3 | PB4 | кнопка **Right** → GND |
| 4 | GND | общий GND |
| 5 | PB0 | OLED **SDA** (+ опц. 4.7 kΩ к VCC) |
| 6 | PB1 | кнопка **Left** → GND **и** 150 Ω → **HPA17A** → GND |
| 7 | PB2 | OLED **SCL** (+ опц. 4.7 kΩ к VCC) |
| 8 | VCC | +3 V с CR2032 через выключатель холдера |

Кнопки: **active LOW**, подтяжка **внутренняя** (`PORTB` pull-up в прошивке) — внешние резисторы на кнопки **не нужны**.

### 3.2 Блок-схема

```
  CR2032 холдер (с выключателем)
       │+              │−
       ▼               ▼
     VCC ──────────── GND
       │    0.1µF      │
       └─────┤├────────┘   ← конденсатор 104 у чипа

            ATtiny85
     ┌────────┴────────┐
     │ PB0 ─── SDA ──────── OLED (на стойках, 4 провода)
     │ PB2 ─── SCL ────────┘   GND, VCC, SCL, SDA
     │ PB1 ───┬── Left btn ── GND
     │        └── 150Ω ── HPA17A ── GND
     │ PB3 ─── Select btn ── GND
     │ PB4 ─── Right btn ─── GND
     │ PB5 ─── RESET (свободен / ISP)
     └─────────────────────┘
```

### 3.3 OLED (провода со стоек корпуса)

Модуль DIYTZT / SSD1306 **128×64 I2C**, 4 пина:

| OLED | Плата / ATtiny |
|------|----------------|
| GND | GND |
| VCC | VCC (+3 V) |
| SCL | PB2 (pin 7) |
| SDA | PB0 (pin 5) |

Экран физически на стойках в корпусе; на макетке — только узлы/провода. SoftI2C в прошивке использует внутренние pull-up; на коротких проводах обычно хватает. Если шина капризная — добавь **4.7 kΩ** от SDA→VCC и SCL→VCC (номинал есть в твоём наборе).

### 3.4 Кнопки (3 шт., 5.8×5.8×10 мм)

У типичного тактового переключателя 4–6 ног: две группы замкнутых контактов. Нужна одна пара **NO** (нормально разомкнуто):

- один контакт → пин ATtiny (PB1 / PB3 / PB4);
- второй → **GND**.

При нажатии пин садится на землю → прошивка читает «нажато».

Подпись в корпусе слева направо (удобно): **◀ Left | ● Select | ▶ Right**.

### 3.5 Пьезо HPA17A

- Тип: **пассивный** пьезоизлучатель (встроенного генератора **нет**) — как требует `buzz.c`.
- Цепь: **PB1 → резистор 150 Ω → вывод HPA17A → GND** (второй вывод пьезо на GND).
- PB1 общий с Left: во время писка пин — OUTPUT (меандр), потом снова INPUT_PULLUP. Резистор защищает пин, если кнопку держат во время звука.
- Полярность у пьезо обычно не критична; если тише ожидаемого — попробуй поменять выводы местами.

### 3.6 Питание и декапл

| Компонент | Куда |
|-----------|------|
| Холдер CR2032 + switch | красный → VCC платы, чёрный → GND |
| Керамика **0.1 µF (104)** | между VCC и GND **у сокета** (короткие выводы) |

Выключатель на холдере — главный power switch устройства.

### 3.7 BOM для этой схемы

| Что | Из твоих комплектующих |
|-----|------------------------|
| MCU | ATtiny85-20PU в DIP-8 сокет |
| Дисплей | 128×64 OLED I2C (провода) |
| 3× кнопка | 5.8×5.8 tactile |
| Пьезо | HPA17A |
| R | **150 Ω** (серия к пьезо) |
| R опц. | 2× **4.7 kΩ** (I2C pull-up) |
| C | **0.1 µF / 104** |
| Питание | CR2032 холдер с выключателем |
| Плата | макетка **80×20 мм** |

## 4. Подробная схема пайки (плата 80×20 мм)

OLED **не** паяется корпусом на плату — только 4 провода (или разъём/колодка) на край платы. Кнопки, сокет, пьезо, питание — на макетке.

### 4.1 Раскладка сверху (вид на плату)

Длинная сторона ≈ 80 мм, короткая ≈ 20 мм. Ориентир — DIP-сокет выемкой **влево** (Pin1 сверху-слева относительно этой схемы).

```
  ← 80 mm →
 ┌──────────────────────────────────────────────────────────────┐
 │  [OLED wires]                                                │
 │   GND  VCC  SCL  SDA     (4 площадки / провода вверх в корпус)│
 │                                                              │
 │   ◯104◯          ┌──────────┐                                │
 │  VCC──┤├──GND    │ DIP-8    │  Pin1 = RESET (площадка ISP)   │
 │                  │  U       │                                │
 │                  │1      8│── VCC                             │
 │                  │2      7│── SCL → OLED                      │
 │                  │3      6│── PB1 → Left + 150Ω→HPA17A        │
 │                  │4      5│── SDA → OLED                      │
 │                  └──────────┘                                │
 │                                                              │
 │   [BTN L]   [BTN S]   [BTN R]     HPA17A (рядом / сбоку)     │
 │    PB1       PB3       PB4        через 150Ω от PB1          │
 │     └────────┴─────────┴───── общий GND                      │
 │                                                              │
 │   BAT+ (красный) ──── VCC     BAT− (чёрный) ──── GND         │
 └──────────────────────────────────────────────────────────────┘
```

На узкой плате кнопки логично поставить **в один ряд** по длинному краю; сокет — ближе к центру; питание — с короткого торца; OLED-провода — с противоположного торца (к стойкам экрана).

### 4.2 Распиновка сокета DIP-8 (что паять к какой ноге)

| Нога сокета | Сигнал | Паять к |
|-------------|--------|---------|
| 1 | RESET | никуда в игре (опц. тонкий провод ISP → Uno D10) |
| 2 | PB3 Select | одна нога кнопки Select; вторая ноги кнопки → GND |
| 3 | PB4 Right | кнопка Right → GND |
| 4 | GND | общий GND: батарея−, OLED GND, кнопки, пьезо |
| 5 | PB0 SDA | провод OLED **SDA**; опц. 4.7k → VCC |
| 6 | PB1 Left+Buzz | кнопка Left → GND; **и** вывод **150 Ω** |
| 7 | PB2 SCL | провод OLED **SCL**; опц. 4.7k → VCC |
| 8 | VCC | батарея+, OLED VCC, декапл 104, опц. pull-up I2C |

### 4.3 Цепь пьезо пошагово

1. От **ноги 6** сокета (PB1) паяешь один вывод резистора **150 Ω**.
2. Второй вывод резистора — на один вывод **HPA17A**.
3. Второй вывод HPA17A — на **GND**.
4. От той же ноги 6 — провод/дорожка на кнопку Left (вторая нога кнопки — GND).

Не ставь пьезо напрямую на PB1 без резистора: при зажатом Left во время beep возможен удар по пину.

### 4.4 Перемычки на perfboard

На односторонней макетке обычно **нет** готовых дорожек как на PCB — соединяй голым проводом / выводами компонентов снизу:

1. **Шина GND:** нога 4 сокета + BAT− + все «земляные» ноги кнопок + земля пьезо + OLED GND + один вывод 104.
2. **Шина VCC:** нога 8 + BAT+ + OLED VCC + второй вывод 104 (+ 4.7k если ставишь).
3. Отдельные короткие перемычки: 2→Select, 3→Right, 5→SDA, 6→Left+R150, 7→SCL.

Перед пайкой отметь маркером на плате: `L`, `S`, `R`, `+`, `−`, `SDA`, `SCL`.

### 4.5 Что нельзя соединять

- VCC с GND
- RESET (нога 1) с GND (чип уйдёт в постоянный reset)
- OLED VCC с 5 V от Uno, пока стоит CR2032 (и наоборот — не питай плату от батареи во время ISP)
- Ноги кнопок между собой без нужды (иначе «залипнут» два входа)

### 4.6 Порядок сборки (рекомендуемый)

1. Паяй **сокет** (не сам чип) — метка Pin1 совпадает с выемкой.
2. Паяй **104** у ног 8 и 4.
3. Паяй **три кнопки** и общий GND.
4. Паяй **150 Ω + HPA17A**.
5. Выведи **4 провода OLED** (подпиши термоусадкой: GND/VCC/SCL/SDA).
6. Припаяй **BAT+/BAT−** с холдера.
7. Прозвони мультиметром: нет КЗ VCC–GND; каждая кнопка замыкает свой пин на GND.
8. **Прошей ATtiny85 отдельно** через Uno (§2), вынь из программатора.
9. Вставь чип в сокет на плате (ориентация!).
10. Подключи OLED на стойках, вставь CR2032, включи switch холдера.
11. Экран должен показать Boot → яйцо; ◀/▶ листают меню; Select кликает.

### 4.7 Быстрая проверка после включения

| Проверка | Ожидание |
|----------|----------|
| Питание | ~2.8–3.2 V на VCC–GND |
| Экран | картинка / яйцо, не «снег» |
| ◀ / ▶ | смена пункта меню + короткий Click |
| ЕДА (после вылупления) | звук Feed |
| HPA17A | слышны писки на действиях |
| Left во время звука | не зависает; после звука кнопка снова работает |

Если экран тёмный, а звук есть — смотри SDA/SCL/VCC OLED. Если экран есть, а звука нет — 150 Ω, HPA17A, общий GND с PB1.
